# Gestor de tareas por proyecto

ESte es un proyecto **Single PAge Aplication SPA** contruida con **JavaScrip Vanilla**, **Vite** y **json-server**. Incluye **CRUD** para la gestion de estos mismas y control de roles.

## Caracteristicas

* Crear y gestionar proyectos.(admin)
* Asignación de tarear a usuarios. (admin)
* Visualizar proyectos y tareas asignadas. (coder)
* Marcar estado de tareas.(coder)

## Herramientas necesarias.

Necesitas:
 * Node.js >= v22.14.0.
 * json-server >= 1.0.0-beta.3.
 * Editor de código.

## Instalación

``` bash
    # 1. Clona este repositorio
    git clone https://github.com/moicanbas/appVite.git
    cd appVite

    # 2. Instala dependencias
    npm install

    # 3. Inicia el servidor de desarrollo
    npm run dev
```
